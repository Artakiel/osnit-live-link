# Partage du live TikTok

Page statique minimale pour ouvrir le live : [ouvrir sur TikTok](https://vm.tiktok.com/ZN9fVnP7synST-fafai/).

Le fichier `index.html` est prêt pour GitHub Pages. **GitHub Pages n’est pas encore activé** sur ce dépôt : l’API a refusé l’activation faute de permission. Pour l’activer, ouvrir **Settings → Pages → Build and deployment**, choisir **Deploy from a branch**, sélectionner `main` et `/ (root)`, puis enregistrer. GitHub indiquera l’adresse Pages lorsque la publication sera prête.

Pour chaque nouveau live, remplacer l’URL TikTok dans `index.html`, vérifier le texte, puis pousser la mise à jour sur `main`. La page n’actualise pas le lien automatiquement.

Le dépôt ne contient qu’une page statique sans lecteur intégré, pixel de suivi, publicité, formulaire ou collecte ajoutée. Les scripts de préparation des messages restent locaux et ne sont pas inclus dans ce dépôt public. La disponibilité de la vidéo dépend de TikTok.
